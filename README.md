# 🛒 سمسار السودان

منصة بيع وشراء وإيجار السيارات والعقارات في السودان — مفاصلة مباشرة داخل المحادثة، والسمسار (المنصة) بيضمن الصفقة.

**التقنيات:** Next.js 14 · Neon Postgres · Vercel Blob · Vercel

## الأمان (المرحلة 1)
- حسابات برقم التلفون + كلمة سر (bcrypt) وجلسة HttpOnly موقّعة، قفل مؤقت بعد 5 محاولات غلط.
- كل البيانات بتمر عبر API في السيرفر بصلاحيات: محادثتك ليك بس، وإعلانك إنت بس البتعدّله.
- رقم التلفون مخفي — بيظهر للطرفين بعد الاتفاق على السعر بس.
- قبول العرض = اتفاق مبدئي (الإعلان بيتحجز)، والبائع بيأكد «تمت الصفقة» أو أي طرف بيلغي.
- حماية CSRF، رؤوس أمان، تحقق من نوع الملفات، حدود يومية ضد الإزعاج.

## التشغيل على Vercel
1. **Storage → Neon** (Create & connect) ← بيضيف `DATABASE_URL` تلقائياً.
2. **Storage → Blob** (Create & connect) ← بيضيف `BLOB_READ_WRITE_TOKEN` (للصور الكبيرة والفيديو).
3. **Settings → Environment Variables:**
   - `AUTH_SECRET` — نص عشوائي طويل (32 حرف أو أكتر)
   - `ADMIN_PHONE` و `ADMIN_PASSWORD` — حساب المدير (بيتعمل تلقائياً أول مرة)
4. Redeploy. الجداول بتتعمل لوحدها.

## التطوير محلياً
